Self-Distillation, briefly

Post-Training, KL-Divergence, Self-Distillation, Credit Assignment.

By Cristian Gutiérrez

29th of October, 2026

From "On-Policy Self-Distillation for Large Language Models", Zhao (ICML 2026)

KL Divergence

Measures similarity (not distance) between probability distributions.

For discrete probability distributions:

$$ D_{KL}(P\mid\mid Q)=\sum_i P(i) \log \frac{P(i)}{Q(i)} $$

For continuous probability distributions:

$$ D_{KL}(P\mid \mid Q)=\int P(x) \log \frac{P(x)}{Q(x)} \, dx $$

Notice that it is not a distance per sé:

$$ D_{KL}(P || Q) \neq D_{KL}(Q||P) $$

In the case of On-Policy Distillation, our probability distribution consists of the next tokens probs over all the next token ids over the vocabulary.

$$ D_{KL}(P\mid\mid Q)=\sum_{i=0}^{248,320} P(i) \log \frac{P(i)}{Q(i)} \qquad \text{where } i \text{ is a next-token id} $$

Notice how each token in our sequence \([1, N]\) will have a prefix, hence, we will start with the next token 1, then the next token 2 (which is conditioned by the previous prefill)…

In self-distillation we do on-policy distillation, but using the model itself with extra context (or hints) as target.

$$ \mathcal{L}(\theta) = D_{KL}(\pi_\theta \mid\mid \pi_{\text{teacher}}) $$

Comment

IMO giving this hint or context to the teacher is the tricky part without a systematic methodology yet. Guiding the teacher towards giving useful feedback remains pretty much an open problem.

Self-Distillation can be modeled as the classical RL of a policy gradient with token-level advantages.

Make \(\pi_\theta(\cdot \mid x)\) match the improved (conditioned) teacher \(\pi_\theta(\cdot \mid x, f)\).

$$ \text{Minimize} \quad \mathcal{L}_{\text{SDPO}}(\theta) := \frac{1}{|y|} \sum_{i=1}^{|y|} \text{KL}\big(\underbrace{\pi_\theta(\cdot \mid x, y_{<i})}_{\text{student}} \,\|\, \underbrace{\pi_\theta(\cdot \mid x, f, y_{<i})}_{\text{teacher}}\big) $$
$$ \text{Maximize} \quad A_i(x, y, f) := \log \frac{\overbrace{\pi_\theta(y_i \mid x, f, y_{<i})}^{\text{teacher}}}{\underbrace{\pi_\theta(y_i \mid x, y_{<i})}_{\text{student}}} $$

Notice we maximize because we swapped \(q\) and \(p\):

$$ \log{\frac{p}{q}} \equiv - \log{\frac{q}{p}} $$

Suppose we have an input prompt asking our student to write a Python function to return all numbers between 1 and n.

The student incorrectly returns \([1, n]\) instead of \([1, n)\).

Then we can condition the teacher, walk the same trajectory and minimize the KL divergence at token-level.
